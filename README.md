# 📖 Descripción

ResumeForge es un proyecto personal cuyo objetivo es demostrar que un currículum también puede ser desarrollado como un producto de software.

En lugar de utilizar plantillas prediseñadas, este CV fue construido completamente desde cero con HTML y CSS, aplicando principios de organización, diseño limpio y mantenibilidad, permitiendo actualizar la información fácilmente y exportarla posteriormente a formato PDF.

Más que un documento, este repositorio representa una forma diferente de presentar mi perfil profesional como desarrollador.

---

# 🎯 Objetivos del proyecto

- Diseñar un currículum moderno y profesional.
- Mantener una estructura fácilmente editable.
- Facilitar la generación de un PDF de alta calidad.
- Aplicar buenas prácticas de maquetación web.
- Servir como una demostración adicional de mis conocimientos en desarrollo Frontend.

# ✨ Características

# 🚀 Cómo visualizar el proyecto

1. Clonar el repositorio.

```bash
git clone https://github.com/SirLian-Dev/ResumeForge.git
```

2. Abrir el proyecto.

```text
ResumeForge/
```

3. Ejecutar el archivo:

```text
index.html
```

No requiere instalación ni dependencias externas.

# 📄 Exportar a PDF

El proyecto fue diseñado para permitir una exportación sencilla a PDF desde cualquier navegador moderno.

Simplemente:

```
Ctrl + P
```

Seleccionar:

```
Guardar como PDF
```
