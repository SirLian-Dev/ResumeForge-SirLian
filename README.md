## 📖 About

ResumeForge is the source code of my personal resume, developed as a lightweight front-end project instead of using traditional design tools.

The objective is simple:

- Build a professional resume with clean and maintainable code.
- Generate a high-quality PDF version for recruiters.
- Demonstrate front-end development skills through semantic HTML and modern CSS.
- Keep the resume easy to update as my professional experience evolves.

Although the project is simple by design, it follows the same philosophy I apply to my software projects:

> Build clean. Build maintainable. Build with purpose.
