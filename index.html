Sobre mí

Mi camino hacia el desarrollo de software comenzó fuera del sector tecnológico. Con formación y experiencia como Técnico Electricista fortalecí mi pensamiento lógico, disciplina y capacidad para resolver problemas bajo estándares estrictos, así como con el trabajo bajo presión, concentración y agilidad en los entornos Gastronómicos.

Durante los últimos años me he especializado de forma autodidacta en ingeniería de software, diseño de APIs REST, bases de datos relacionales y arquitectura de aplicaciones utilizando Java y el ecosistema Spring.

Hoy mi objetivo ya no es únicamente conseguir un empleo. Estoy construyendo productos reales que generen valor, mientras continúo creciendo como ingeniero de software y buscando colaborar con diferentes equipos profesionales.

Proyecto Principal

CareerTrack

CareerTrack es el producto de software que actualmente desarrollo desde cero.

El objetivo del proyecto es ayudar a profesionales a organizar, optimizar y potenciar su crecimiento laboral mediante herramientas tecnológicas accesibles.

Como fundador participo en todas las etapas del desarrollo: investigación, arquitectura, backend, frontend, bases de datos, documentación técnica, diseño del producto y mejora continua.

Java Spring Boot PostgreSQL React REST API Arquitectura

Proyectos
